Tentang kursus

Mau portfolio sinematik hitam-merah seperti punya saya, lengkap dengan animasi scroll, galeri karya, dan bagian award? Kamu tidak perlu coding. Cukup copy satu prompt, paste ke AI coding agent, lalu tambahkan fotomu dan instruksi tambahan.

Template ini gratis. Lisensi dan kredit ada di bagian paling bawah.

Yang kamu dapat

  • Hero dengan huruf raksasa dan foto cut-out, parallax saat scroll
  • Galeri karya dengan filter, pencarian, dan dialog video / foto / breakdown 3D
  • Bagian award, tentang saya, perjalanan karier, dan form kontak ke WhatsApp
  • Responsif sampai layar 320px, dengan tombol Motion on/off
  • Animasi "dibangun banyak agent" yang diputar sekali di akhir (opsional)

Preview: https://renando.duingzcreative.site

Yang perlu disiapkan

  1. AI coding agent yang bisa membuat file dan menjalankan perintah di komputermu, misalnya Codex (ChatGPT), Claude Code, atau Cursor.

    Catatan: agent seperti ini umumnya butuh paket berbayar (misalnya ChatGPT berbayar untuk Codex, atau Claude berbayar untuk Claude Code) atau kredit API. ChatGPT versi gratis tidak bisa membuat dan menjalankan proyek ini. Aturan paketnya bisa berubah, jadi cek halaman harga masing-masing.

  2. Node.js 20 atau lebih baru.

  3. Satu folder kosong untuk proyekmu.

  4. Fotomu, kalau mau potretnya dibuat ulang (opsional). Wajah jelas dan cahaya rata paling aman.

  5. Daftar karya, pengalaman, dan kontakmu.

Langkah

  1. Buka folder kosong tadi di AI agent-mu.

  2. Copy seluruh prompt di bagian Prompt di bawah, paste ke agent, lalu tulis permintaanmu di bawahnya. Contoh:

    Namaku Sinta, aku fotografer dari Bandung. Fotoku ada di foto-sinta.jpg. Ganti warna aksen jadi biru. Karyaku: (daftar karya). Kontak WhatsApp 62812xxxx. Hapus bagian breakdown 3D.

  3. Tunggu sampai selesai. Agent menulis proyek, mengunduh gambar, menjalankan build, lalu memberi tahu alamat situsmu, biasanya http://localhost:4173.

  4. Buka alamat itu di Chrome. Kalau sudah pas, upload index.html dan folder Asset/ ke hosting statis (GitHub Pages, Netlify, atau Vercel).

Cara melihat animasi "dibangun banyak agent"

Kamu tidak perlu memantau localhost saat situs sedang dibangun. Agent bekerja sendiri dulu. Animasinya baru diputar satu kali di akhir, setelah situsmu jadi: puluhan kursor berlabel nama merakit halamanmu dari kosong, turun sendiri sampai bawah, sekitar satu sampai dua menit, lalu halaman kembali normal.

  • Kalau agent-mu punya browser (misalnya Claude Code dengan browser, atau Codex dengan Playwright): ia membuka situsmu dan memutarnya sendiri. Kamu tinggal menonton jendela browser itu. Mau merekam? Mulai rekam layar sebelum agent menjalankannya.
  • Kalau agent-mu tidak punya browser: buka alamat situsmu (misalnya http://localhost:4173) di Chrome, tekan F12, buka tab Console, tempel satu baris dari bagian 10 prompt, lalu tekan Enter. Kalau Chrome meminta, ketik allow pasting dulu.
  • Alamat localhost hanya hidup selama agent masih menjalankan servernya. Kalau sudah mati, minta agent "jalankan lagi situsnya".
  • Tidak perlu memasang ekstensi apa pun. Animasi ini hanya tampilan untuk ditonton dan tidak ditambahkan ke kode situsmu.

Tips

  • Satu perubahan per pesan. Agent lebih akurat kalau dikasih perintah kecil.
  • Jangan minta agent "memperbaiki desain". Prompt ini sengaja melarang itu supaya hasilnya tetap sama dengan template.
  • Jangan masukkan nomor, award, atau klien yang tidak benar. Kosongkan saja kalau belum punya.

Kalau macet

  • Agent melapor gagal mengunduh gambar atau data: koneksi bermasalah. Minta agent mencoba lagi. Jangan biarkan agent membuat gambar pengganti sendiri.
  • Agent mengubah desain atau menambah library: minta ia mengembalikan ke kode asli di prompt.
  • Gambar tidak muncul: periksa folder Asset/ ikut ter-upload dan jalurnya relatif (./Asset/...).
  • Halaman kosong: jalankan npm run build lagi dan lihat error-nya di konsol browser.

Prompt

Salin semuanya, dari baris pertama sampai terakhir. Prompt sengaja berbahasa Inggris supaya hasilnya sama di agent mana pun.

# Recreate this site as a static project: RENANDO — Cinematic Editor & VFX Portfolio

You are an expert creative front-end developer. Produce a working project that reproduces the site below **exactly**: same layout, copy, visuals, motion and interaction. React 19 + Framer Motion 12 bundled by esbuild into a plain static site (`index.html` + `Asset/`). No framework, router or CSS library beyond what is listed.

Where this document quotes source verbatim (sections 3 to 5) it is the project's own code. **Write it to disk as it stands.** Every number in it is the shipped value. Nothing in it is a suggestion, and nothing may be "improved".

## 1. What it is

A one-page dark film portfolio for an editor / VFX artist. Black ground `#090909`, warm-white type `#f2efeb`, crimson accent `#e32b3c`, film grain overlay, thin section rules, oversized red condensed lettering behind a cut-out portrait. Fonts: **Anton** (display), **Manrope** 400–800 (body), **Caveat** 400/500 (handwritten accent), loaded from Google Fonts by `index.html`.

Sections in order: sticky header → Hero (giant `PORTFOLIO` lettering, portrait, intro, stats, CV link) → Selected work (featured three, then the full archive with category filters, search, load more, project dialog with video / still / 3D render stages, and the brand-logo strip) → Recognition & Awards → Breakdown (before/after slider) → About (education, skills, process, quote) → Journey (experience accordion, milestones) → Contact (links, reel card, WhatsApp brief form) → footer.

Motion (all Framer Motion, all inside `src/app.jsx`): global easing `[0.22, 1, 0.36, 1]`; reveal-on-scroll `y 32 → 0`; scroll-linked hero parallax; magnetic buttons (`stiffness 220, damping 20`); spring reading-progress bar; auto-scrolling brand rail; animated filter underline with `layoutId`; dialog spring-in. A header **Motion** toggle (saved in `localStorage` as `renando-motion`) and `prefers-reduced-motion` switch every non-essential animation off. No loader, no scroll hijacking.

Responsive: breakpoints at 1100, 800, 600 and 370 px (`max-width`) and 1600 px (`min-width`), plus `(hover:none)`. No horizontal overflow from 320 px up. Touch targets at least 44 px.

function MediaImage({ src, alt, className = '', priority = false, ...props }) {
  const [state, setState] = useState('loading');

function Magnetic({ children, className = '', ...props }) {
  const enabled = useContext(MotionContext);
  const x = useSpring(0, { stiffness: 220, damping: 20 });
  const y = useSpring(0, { stiffness: 220, damping: 20 });
  return <motion.a className={className} style={{ x, y }} onPointerMove={e => {
    if (!enabled || e.pointerType !== 'mouse') return;
    const r = e.currentTarget.getBoundingClientRect();
    x.set((e.clientX - r.left - r.width / 2) * 0.12); y.set((e.clientY - r.top - r.height / 2) * 0.2);
  }} onPointerLeave={() => { x.set(0); y.set(0); }} {...props}>{children}</motion.a>;
}

  const progress = useSpring(scrollYProgress, { stiffness: 100, damping: 28, restDelta: 0.001 });
  useEffect(() => { document.documentElement.dataset.motion = enabled ? 'on' : 'off'; }, [enabled]);
  const toggle = () => { setMotionOn(!motionOn); try { localStorage.setItem('renando-motion', motionOn ? 'off' : 'on'); } catch {} };
  const close = React.useCallback(() => setProject(null), []);
  return <MotionContext.Provider value={enabled}>
    <MotionConfig reducedMotion={enabled ? 'user' : 'always'} transition={{ ease: EASE }}>
      <a className="skip-link" href="#portfolio">Lewati ke karya</a>
      <motion.div className="reading-progress" style={{ scaleX: enabled ? progress : scrollYProgress }}/>
      <Header enabled={enabled} onToggle={toggle}/>
      <main>

        <Portfolio onProject={setProject}/>
        <Awards onProject={setProject}/>
        <Breakdown/>
        <About/>
